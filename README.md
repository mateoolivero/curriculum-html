# Single-Page HTML CV

Curriculum Vitae desarrollado como **una página HTML única**, enfocado en **estructura semántica, SEO básico y buenas prácticas de marcado**, siguiendo el proyecto *Single-Page CV* de roadmap.sh.

El objetivo del desarrollo fue construir una base sólida, limpia y escalable, preparada para ser estilizada posteriormente con CSS.

---

## 🧩 Descripción del proyecto

El sitio presenta un CV completo en una sola página, organizado de forma clara y accesible, utilizando únicamente HTML.

Se priorizó:
- Semántica correcta
- Legibilidad del código
- Preparación para SEO y redes sociales
- Compatibilidad entre navegadores

---

## 🏗️ Estructura implementada

La página está organizada con etiquetas semánticas:

- `<header>`: información principal y encabezado del CV  
- `<main>`: contenido central  
- `<section>`: educación, experiencia, habilidades  
- `<footer>`: información de contacto  

Esta estructura facilita la accesibilidad, el mantenimiento y futuras mejoras visuales.

---

## 🔍 SEO y metadata

El proyecto incluye configuración básica de SEO en el `<head>`:

- `<title>` optimizado
- `<meta name="description">`
- `<meta charset="UTF-8">`
- `<meta name="viewport">`
- Etiquetas Open Graph para compartir en redes sociales
- Favicon configurado

Esto permite una correcta indexación y una presentación consistente en buscadores y plataformas sociales.
